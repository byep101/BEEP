# Legacy reference FASTAs

No legacy reference FASTA copies were present for TxtC v0.1.

The official raw FASTA sources for this package are:

- `data/raw/ncbi/AAW49320.1_TxtC_Streptomyces_turgidiscabies_Car8.fasta`
- `data/raw/uniprot/Q8VS75_TxtC_UniProt.fasta`

Because these two sequences are equal length but not identical, use `metadata/TxtC_AAW49320.1_vs_Q8VS75_sequence_mismatches_v0.1.csv` before residue-level mapping.
