# TamI representative-query supplemental search

The representative query set was selected from the final TamI round-2 model after TamI-reference numeric QC, full-length MSA, focus deduplication and three-anchor motif QC.

The UPGMA distance tree is used only to diversify search queries. It is not treated as a calibrated phylogeny or functional proof.

Every auxiliary-query hit remains a discovery candidate. Before intake, it must be aligned back to TamI reference ADC79647.1 and pass the unchanged TamI-reference identity, coverage, length, ambiguity, exact-deduplication and motif checks.
